# STLサンプルファイルの置き場所

このフォルダーの直下に `.stl` ファイルを追加してください（ASCII / Binary STL両対応）。

`develop` にプッシュするとGitHub Actionsのビルド時に `index.json` を自動生成し、開発用のSTL Viewerに選択肢が現れます。 `main` にマージすると本番側にも反映されます。

- ファイル名が選択肢の名前になります（拡張子は省略）。
- 日本語名・空白入りファイル名も使えます。
- サブフォルダーは探索しません。
- 1ファイルの読み込み上限は80 MiBです。
- `index.json` は自動生成ファイルです。手動編集・コミットは不要です。
