# 仕様

## 入力

- ユーザーが指定したローカルの`.stl`（大文字小文字を区別しない）
- ASCII STL / Binary STLの両方
- ファイルサイズの上限80 MiB、空ファイル不可
- 一度に表示するモデルは1つ（次のファイルで置換）
- ローカルSTLはネットワークへ送信しない
- サンプルSTLは同一GitHub Pages上の `samples/` から取得して表示
- `public/samples/` 直下に置いた `.stl` からビルド時に一覧を自動生成。0件なら選択欄を無効化

## 表示

- Three.js `STLLoader` を使用
- STLには単位・上向き軸の正式な指定がないため、慣例に従いZを上として表示
- 読み込み時にバウンディングボックス中心を原点へ移動
- モデル全体が見えるようカメラを自動配置
- 左ドラッグ／1本指：回転、右ドラッグ／2本指：移動、ホイール／ピンチ：ズーム
- 視点リセット、モデル色選択、ワイヤーフレーム、グリッド、座標軸の切替

## モデル情報

- ファイル名、ファイルサイズ、三角形数
- X/Y/Zの外形寸法（元のSTL座標の単位）
- 無効なSTLはエラー表示し、以前の正常な表示を保持

## 制約

- 単位推定、メッシュの補修、体積計算、複数モデル比較は初期版では非対応
- ブラウザGPUおよび端末メモリが必要
- WebGLが使用できない環境ではエラーメッセージを表示
